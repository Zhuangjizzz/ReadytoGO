# AI 行程输入与确认

`AiPlanInput` 展示输入、地图候选和待确认草稿，`useItineraryDraft` 管理解析、地点查询与取消。服务端使用已有 `/api/v1/assist/parse`、`/places/search` 和 `/plans/preview`，模型提示词及供应商接入沿用 AI 服务。

## 从文本到确认地点

输入支持中英文，提交范围为 1–2,000 字符。超过上限时保留完整输入，提示删减并禁用解析提交。解析只返回原文片段、顺序、中文检索词、备注和需求；最终位置必须来自地图搜索或已校验的手选点。

解析后的每一条使用稳定草稿 ID，独立保存检索词、地图候选、已选 Place、备注和查询状态。正常的 1–10 站自动按最多两个并发请求匹配；超过 10 站时保留全部条目并停止自动批量匹配，用户可以删减、重排和逐条搜索。没有匹配、同名结果或失败项都留在草稿中。

用户可以修改检索词、选择具体地址、打开共用地点选择器、删除、添加、重排及编辑备注。时间只作文字备注。原文片段、地图名称和模型提示均按普通文本渲染。

解析项可以携带可选的 `noteKind: "source_context"`，表示备注保留了原文上下文，可能涉及多站，不能当作已分配给单站的时间安排。草稿以最多 2,000 字符的文本框完整接收备注，并明确提示核对。用户主动修改备注后去掉该标记，作为普通站点备注保存。已确认的长上下文在编辑页与结果页使用可展开的小块展示；普通备注保持原来的展示方式。

全部条目选定为有效北京地点且站数为 1–10 后，用户才可确认替换当前行程。确认复用 `LocalPlanController.replaceStops`，为每次游览生成新 stopId，并原子清理原计划结果。相同 POI 或相同坐标只触发重复提醒，不去重；用户可确认保留重复游览。

## 需求与失败恢复

- `proposedPreference=null` 对应“沿用当前选择”，使用确认时的最新偏好。明确 `any` 或 `seated_required` 显示为可编辑选项。额外需求单独提示，不转换为新筛选条件。
- 解析失败保留原文、已有草稿及已选地点；当前行程的手选厕所与跳过状态不会改变。用户仍可重试、编辑草稿或使用手动规划。
- 修改原文后，旧草稿不能自动确认。用户可以重新解析，或明确选择“将修订草稿用于当前文本”。手动接续保留地点和备注，清理旧文本的 AI 提示与偏好提案，恢复为沿用当前需求，并标记为手工核对的草稿；最后仍需确认替换。
- 清除行程会同步清除原文和未确认草稿，取消相关等待。输入文本框不单独保存，服务日志不记录完整输入；确认后的地点、需求和备注按规划模块保存，其中备注可包含原文片段或完整原文上下文。

`PlanStop.noteKind` 随用户确认保存和刷新恢复，`schemaVersion` 仍为 1；没有该字段的旧存档继续作为普通备注使用。更换景点、重排和语言切换保留备注标记。浏览器 GPS 仍只属于当前会话，不随备注增加持久字段。

## 并发与取消

解析写回同时检查请求版本、原文和当前上下文（语言、偏好、计划 revision、页面是否活动）。输入变化、手动草稿操作或上下文变化使旧解析失效，即便传输未及时响应 abort 也不能回写。

地图请求按草稿行 ID 和检索词检查；换词、删行或手选会取消对应请求。自动匹配批次另有取消代数，原文变化、重新解析、离开页面或丢弃草稿后，不继续发送旧批次的剩余请求。重排只改顺序，仍在查询的行保持身份。

客户端解析有 15 秒等待界限；地图匹配允许最多 100 秒，覆盖服务端共享队列的 90 秒等待、5 秒外部请求及传输余量。超时后解除忙碌状态并允许重试，等待中也可修改或取消。供应商调用及模型修复仍由服务端已有预算约束。共用 PlacePicker 在改词、切换语言和卸载时也使旧响应失效。

## 验证与真实记录回放

`tests/dom/ai-plan.test.tsx` 在隔离 JSDOM 中覆盖确认前不改计划、迟到响应、失败保留、超站数、重复、无显式需求、否定需求、未匹配修正、输入上限、队列取消、手动接续、清除、长上下文确认/恢复、主动编辑转普通备注与旧存档兼容。`tests/ai-plan-flow.test.ts` 通过真实业务 HTTP 路由串联解析、地点搜索与逐站预览；外部模型和地图在该测试中使用边界替身。

`tests/fixtures/recorded-ai-itinerary.json` 是已有真实千问解析与高德三站预览的有界回放，保留九张初始卡片的实际候选 ID、设施、路线和说明，省略游标及原始来源列。对应 DOM 回放测试核对确认地点 POI、页面卡片 ID、说明和来源，未重新调用供应商。该记录只用于测试和交付证据，生产逻辑没有固定景点或评测文本分支。

上述页面检查是离线组件与 HTTP 验证，没有访问被拒绝的实际应用浏览器入口，也不代表真机或最终视觉验收完成。
