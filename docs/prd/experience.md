# 用户流程与双语

实现页面、起点、景点规划、导航、询问卡或本机保存时，读取本文。返回 [PRD 总入口](README.md)。

## 页面与首页

| 页面 | 路径建议 | 内容 |
| --- | --- | --- |
| 首页 | `/` | 找附近厕所、规划行程、语言切换、询问卡 |
| 附近结果 | `/nearby` | 起点、需求、步行范围、列表与地图切换 |
| 地点选择 | 共用弹层 | 名称搜索、候选地址、地图选点、确定起点 |
| 厕所详情 | `/toilets/:id` | 设施、推荐说明、地址、开放与进入信息、导航 |
| 行程编辑 | `/plan` | 按顺序添加景点、AI 辅助填入、全局需求 |
| 行程结果 | `/plan/result` | 每站推荐、备选、换一个、跳过 |
| 询问卡 | `/phrases` | 固定双语句子与大字卡片 |

首次打开使用英文，用户可以切换中文；保存显式语言选择。首页提供 `Find a toilet` 和 `Plan my stops` 两个主要入口。

需求为两个单选项：`No preference` / 无特殊要求，`Seated toilet needed` / 需要坐便。首次默认无特殊要求，之后沿用本机选择。需求含义和推荐资格在[推荐规则](rules.md#需求与设施线索)维护。

首版即时搜索用控件完成。若扩展自然语言即时搜索，先把解析结果显示为可编辑的起点和需求，再由用户提交。

## 起点与附近搜索

1. 用户点击找附近厕所时请求定位，显示当前位置并允许修改。
2. 定位拒绝、不支持或超时后，提供地点搜索或地图选点。定位精度较差时显示大致位置，允许继续查询或改起点。
3. 手选地点显示名称、所在区和地址，用户选定具体结果。北京以外的起点提示选择北京地点。
4. 根据需求与范围展示候选，允许查看详情、地图、扩大范围或更换起点。

持续显示结果的计算起点，例如“从王府井地铁站 A 口出发”。选中卡片时突出地图点，点击地图点时显示对应卡片；默认先读列表，地图按需加载。

已取得的结果可以渐进展示。修改条件后，旧请求不能覆盖新结果；返回列表保留筛选和滚动位置。查询状态至少区分加载中、部分结果、完成、无合适候选、无候选和服务失败，并提供重试或换起点入口。

## 结果卡片与详情

卡片展示中文名、英文辅助名、步行时间与距离、设施线索、开放/进入信息、简短推荐理由和导航入口。未知字段使用短标签，避免整张卡片堆叠警告。

详情展示已有设施属性、来源名称、AI 分析理由、地址和入口说明。数据年份、核验日期及证据有效期不作为页面展示项。对坐便可能性的分析使用“有坐便线索”或“可能有坐便”，不使用“已现场核验”文案。

步行时间按算路秒数向上取整，最低显示 1 分钟；筛选使用原始秒数。距离以米展示，超过 1 公里显示一位小数公里。路线缺失时展示直线距离或“步行时间暂不可用”，不由直线距离生成步行分钟。

## 景点规划

### 编辑与 AI 输入

用户按顺序添加 1–10 个北京地点，可删除、更换和调整顺序。重复地点提醒一次，用户可选择继续添加。大型景点可以选入口或集合点，也可直接使用所选地点的位置。

用户可以粘贴中英文行程，由 AI 填入地点和需求，见 [AI 行程解析](ai.md#行程解析)。解析结果先显示为待确认列表；同名或无法匹配的地点提供候选和修改入口，超过 10 站时让用户删减。确认前保留原行程。

行程中的时间可保留为文字备注，规划只按景点周边推荐。地点顺序以用户输入及编辑结果为准。

### 每站结果

每站显示景点起点、需求、一个主推荐和最多两个备选；最多三张初始卡片，更多候选进入该站完整列表。该列表沿用规划上下文，不因当前闭馆就排除周期开放的地点。

主推荐可使用[规则定义的设施推断结果](rules.md#分组与排序)，同时说明推荐依据。缺少匹配结果时说明情况，显示可选的其他或更远候选，允许换起点和扩大范围。

多站独立加载，成功站先展示。某站无候选与某站查询失败使用不同提示，失败站可单独重试。

### 修改与选择

“换一个”打开该站候选供用户替换；“跳过”只跳过该站厕所安排，保留景点。用户选择与跳过状态存于本机。

调整顺序只改变展示顺序；更换某站起点重新查询该站，改变全局需求或进入条件重新计算全部站。旧选择不再符合条件时提示重新选择。同一厕所可出现在不同站下，不跨站去重。

每站提供“从当前位置查找”，转入附近搜索并重新获取当前位置。

## 导航与地图降级

提供打开高德 App、网页路线、复制中文名称地址三个入口。网页入口始终可见；App 唤起失败时仍能继续操作。

用户可以选择从当前位置或当前搜索起点出发。改变导航起点后重算距离时间，不能沿用景点起点的数字。没有当前位置时使用已选择的起点。

有可用目的地坐标即可交接地图导航，不增加现场确认、日期复核或二次审批流程。没有坐标时保留详情、复制地址与手动地图搜索。地图 SDK 加载失败时保留列表和上述入口。

## 双语与询问卡

界面和固定文案提供英文、中文；英文辅助翻译与中文原名同时展示。语言切换保留需求、起点、行程和选择。

| 中文 | 英文 |
| --- | --- |
| 资料记载有坐便 | Seated toilet listed |
| 可能有坐便 | May have a seated toilet |
| 坐便信息未知 | Seated toilet information unknown |
| 营业时间未提供 | Opening hours not listed |
| 进入条件未提供 | Access details not listed |
| 超出所选步行范围 | Beyond your selected walking time |
| 从所选景点出发 | From your selected attraction |

询问卡使用五句固定文案：

| 中文 | 英文 |
| --- | --- |
| 请问这里有成人可用的坐便器吗？ | Is there a seated toilet that an adult can use here? |
| 请问厕所现在开放吗？ | Is the toilet open now? |
| 请问游客可以使用吗？ | Can visitors use this toilet? |
| 请问厕所入口在哪里？ | Where is the toilet entrance? |
| 请问有卫生纸吗？ | Is toilet paper available? |

中文大字在上、英文在下，支持上一句、下一句、返回和横屏。建议中文主句至少 28 px，触控区域至少 44 px。文案随应用打包，展示不依赖模型。

## 本机保存

保存一份当前行程、语言、需求、进入条件设置、每站选择和跳过状态。刷新后恢复，清除行程时删除相关结果缓存与选择，语言可保留。

浏览器定位只用于当前会话，手选景点可随行程保存。结果缓存用于加速返回，过期后重新请求；缓存时间是工程参数，不作为设施可信度门槛。

存储不可用时继续使用内存状态，提示关闭页面后可能丢失。未知存储版本提示重新建立行程，保留可继续使用的页面操作。
