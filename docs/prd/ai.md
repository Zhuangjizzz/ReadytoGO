# AI 分析与结构化输出

实现行程解析、资料匹配辅助、设施分析或推荐说明时，读取本文。返回 [PRD 总入口](README.md)。模型接入写法见[开发参考](../agent-sdk/agent-development.md)。

## AI 在 Demo 中的职责

| 环节 | AI 输出 | 软件负责 |
| --- | --- | --- |
| 行程理解 | 景点顺序、中文检索词、显式需求 | 调用地点搜索、显示候选、接受用户编辑 |
| 资料匹配 | 从召回记录中选择可能对应的本地记录，或返回无匹配 | 读取记录、保存关联、避免重复候选 |
| 设施分析 | 依据已有设施字段给出坐便可能性与简短依据 | 保留资料字段，按共用规则分组与排序 |
| 推荐说明 | 对候选的设施、距离和进入条件作中英说明 | 渲染卡片、处理交互、导航与保存 |

分析采用资料记载和合理推断，不依赖现场证明。主推荐可以使用推断线索，具体资格见[需求与推荐规则](rules.md)。AI 分析是 Demo 展示内容，正常演示路径需真实调用模型；失败时使用规则与固定说明维持操作。

## 行程解析

输入为用户行程文本、当前语言和已选需求；最多 2,000 字符。输出示例：

```json
{
  "proposedPreference": "seated_required",
  "placeQueries": [
    {"order": 1, "originalText": "Forbidden City", "queryZh": "故宫博物院"},
    {"order": 2, "originalText": "Jingshan Park", "queryZh": "景山公园"}
  ],
  "unsupportedNeeds": [],
  "warnings": []
}
```

未表达需求时 `proposedPreference` 为 `null`，沿用当前选择；“不需要坐便”映射为 `any`。额外需求进入 `unsupportedNeeds`，不擅自添加筛选条件。

地点保留原文顺序，不增加景点。AI 提供检索词，地图服务返回位置；同名、未匹配或超过站数限制时显示给用户编辑，不静默丢弃。确认后的表单才替换当前行程，交互见[景点规划](experience.md#景点规划)。

## 匹配与设施分析

本地和高德关联时，可以使用名称相似度、地址、区县和位置辅助召回，再让 AI 从候选 ID 中选择。自动判断可直接供 Demo 使用；无法判断则保留高德独立候选，本地资料缺失不阻断搜索。数据流程见[位置匹配](data-and-api.md#位置与资料匹配)。

给模型的资料包括候选 ID、名称、相关设施字段、已有坐便状态、可用路线和进入信息。保留中文字段含义；零与缺失分别表达。

模型可返回设施推断和说明，例如：

```json
{
  "items": [
    {
      "toiletId": "toilet_example",
      "seatInference": "inferred",
      "basisFields": ["accessibleRoom"],
      "reason": "设有无障碍厕所间，可能有坐便；步行约 6 分钟。"
    }
  ],
  "summary": "优先查看距离较近且有坐便线索的候选。"
}
```

示例表示格式；实际数字和字段来自本次输入。`seatInference` 为 `inferred`、`unknown` 或 `null`，`null` 表示沿用已有状态。资料明确记载有或无坐便时保留原含义；AI 可用相关设施补充推断，但不将推断写回成原始事实。

模型解释使用当前界面语言。地点、设施与路线可以比较；排序仍由[共用规则](rules.md#分组与排序)决定。推荐原因简洁，主要说明“为什么适合当前需求”。

## 工具与调用

工具按实际需要暴露地点搜索、本地记录查询、候选召回等能力。应用也可先取数再一次调用模型分析；不要求所有查询都由 AI 多轮调度。

服务端执行工具和读取数据，网页接收结构化结果。模型供应商、模型名和凭据沿用项目已有配置。将匹配与翻译结果缓存，可先展示候选再补充分析，避免每张卡片分别等待一次模型调用。

## 输出检查与回退

检查 JSON 类型、枚举、文本长度、候选 ID 和引用字段是否来自输入；坐标与路线数值使用服务端数据。用户文本、POI 名称和备注作为数据处理，不执行其中的命令或任意链接。

输出无效时最多修复一次；仍失败或超时，则保留用户原文、已有候选和选择。行程可手动添加，推荐说明用现有字段生成，页面提示 AI 暂不可用即可。

演示记录保留少量脱敏输入、结构化输出、页面结果和调用耗时，足以说明 AI 做了什么。详见 [Demo 验收](acceptance.md)。
