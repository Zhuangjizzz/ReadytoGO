# 偏好、证据与推荐规则

实现需求字段、硬性条件、设施证据、推荐校验或信息展示时，读取本文。返回 [PRD 总入口](../ReadytoGo-PRD-v2.0-Beijing.md)。

## 偏好字段

需求来自用户描述、标签和已保存的显式偏好。未表达的条件表示没有额外要求，不表示已判断用户的身体状况。

| 字段 | 取值 | 含义 |
| --- | --- | --- |
| `seat` | `any` / `prefer_seated` / `require_seated` | 无坐便偏好、偏好坐便、必须有坐便线索 |
| `comfort` | `normal` / `high` | 无额外设施偏好、偏好设施条件较高 |
| `companions` | `elderly` / `child` / `infant`，可多选 | 陪同需求，供 AI 比较家庭或无性别设施 |
| `mobility` | `none` / `limited_walking` / `wheelchair` | 无额外行动要求、少走路、需要无障碍厕位证据 |
| `maxWalkMinutes` | `null` / 5 / 10 / 15 | 期望步行时长，用于偏好和较远提示，非候选隐藏条件 |
| `tipTopics` | [贴士 ID](experience.md#如厕贴士) | 用户相关贴士 |
| `uiLanguage` | `en` / `ja` / `ko` | 界面与结果文案语言 |

没有需求时使用无额外限制的查询；使用者选择“就近查找”不会在后台添加文化默认偏好。用户只说“近一点”时，保留原有硬性条件。

## 硬性条件与 AI 推荐

- `require_seated` 的首选只接受下述 `strong` / `likely`，`unknown` 只能作为未核实备选。
- `wheelchair` 的首选需要明示的无障碍厕位、无障碍厕所间或高德无障碍厕所类型依据；只有第三卫生间字段不足以替代该要求。
- 明确处于公示时段外的候选放入单独区域，不作为急需首选。
- 用户明确的硬性要求由程序校验；只有用户明确修改时才可以放宽。

满足硬性条件后，由 AI 权衡步行距离、坐便偏好、同行便利和设施条件，给出顺序与理由。没有额外偏好时以就近为主要目标。

“近一点”意味着更重视距离；若没有更近且满足硬性要求的候选，应说明原因。候选步行时间缺失时如实标记，不能比较出未经证实的分钟差。

## 坐便证据

| 状态 | 数据条件 | 展示含义 |
| --- | --- | --- |
| `strong` | 政府记录第三卫生间数量 ≥1 | 列有家庭/第三卫生间，通常包含坐便；未现场核实 |
| `likely` | 列有无障碍厕位或无障碍厕所间，或高德 `typecode=200303` | 有坐便线索；未现场核实 |
| `unknown` | 无上述字段支持 | 坐便情况未知 |

证据来自工具返回的高德信息和已选择的本地记录。名称含“无障碍”本身不能升级证据；多个有效来源同时存在时保留各自依据，取较强的坐便线索。

没有现场核实状态或未经验证的百分比。相关设施详情包含礼让提示：`Please give priority to people who need accessible or family facilities.`

## 设施等级

仅对政府来源资料计算 `Facility level`，按字段计分并限制在 1–5 星：

| 字段 | 计分 |
| --- | --- |
| 类别 | 一类 3，二类 2，三类或空 1 |
| 管理间 = 有 | +1 |
| 盥洗室 = 有 | +1 |
| 农村公厕 = 是 | −1 |

清洗时先统计实际类别取值并校对映射，保留计分依据。等级表示列出的设施条件，不是实时卫生或用户评分；没有政府资料时显示 `Not rated`。

管理间只展示为“列有管理间”，不由该字段推出当前有人值守。AI 可以将较高设施等级作为 `comfort=high` 的比较依据。

## 记录过滤

政府清单只保留“指标状况=现有”且“冲洗方式=水冲”的记录，取值白名单按实际数据核对。坐标无效且无法可靠修复的记录剔除并记录原因。

高德候选按返回类型精确过滤，见[高德搜索](data-and-api.md#高德搜索)。

## 开放信息

仅有政府来源、没有时段信息时显示 `Hours not listed`。高德时段能够明确解析时显示 `Within listed hours (not verified open)` 或 `Outside listed hours`；无法解析时显示 `Hours unknown`。

使用 `Asia/Shanghai` 当前时间。解析明确的 `24小时营业`、`HH:mm-HH:mm` 等格式；跨日、节假日或含糊条件无法判断时保持未知并保留原始文本。

高德与本地资料关联后仍保留高德的营业字段，不因政府缺少时段而覆盖它。公示时段不等于实际开放，界面不显示 `Open now`。

## 步行与进入信息

- 只有真实步行算路返回的耗时才显示 `X min walk`。
- 算路失败时显示地图距离与 `Map distance only`；距离也不可用时显示 `Walking time unavailable`。
- 超过期望步行时长标 `Long walk`，无设置时提示阈值为 15 分钟；少走路需求可使用 10 分钟作为初始期望。较远候选仍可展示。
- 仅在明确存在室内信息时显示 `Inside venue` 与楼层；进入信息标 `Entry/access not verified`。没有室内字段时保持未知，不从名称猜楼层。
- 室内属性本身不作为降权依据。路线可能只到场所坐标，不保证入口、楼内通行或轮椅路线可达。

## 搜索与分区

默认搜索半径 1 公里；必须坐便且首选为空时自动扩大一次至 2 公里，先展示已有备选。扩大后保留 `Search expanded for sitting-toilet evidence` 提示；其他需求提供手动扩大入口。

结果按首选、未核实备选、公示时段外候选组织，时段外区域默认折叠。没有合格首选时保留真实备选并说明限制，不能将备选包装为满足硬性要求。

## 来源与规模

- 保留中文原名和地址，展示经过核对的翻译与地标描述。
- 坑位数量是规模信息，不推断排队时间。
- 政府来源显示文件更新日期，高德来源显示本产品取数时间；均不代表现场核实时间。
- 本地记录如何与高德候选对应，统一遵循 [AI 关联流程](ai.md#本地记录关联)。
