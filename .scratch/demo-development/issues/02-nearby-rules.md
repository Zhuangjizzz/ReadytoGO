# 02: 完整附近推荐与渐进结果

Status: claimed
Type: task
Stage: 2
Blocked by: 01

Parent: [开发规格](../spec.md)

## What to build

切换需求、范围和进入条件，理解分组并继续加载或重试。

## Acceptance criteria

- [ ] 四种坐便状态、五组、稳定排序、10/20 分钟和 5/10 公里扩展正确。
- [ ] 上海时区跨午夜、附近/规划开放区别、进入条件和路线未知/不可达正确。
- [ ] 页面显示计算起点、状态、控制和加载更多，旧版本不能覆盖新结果。
- [ ] 有限批次、pendingWork、显式重试、游标和缓存有正确结束条件。

## Execution constraints

- 使用独立工作树与分支，开始确认基于集成分支，完成前合入集成分支最新提交。
- 使用 tdd，在规格约定的公开 HTTP、正式导入及浏览器行为入口验证。用户授权直接执行，不重复询问。
- 实现通用输入行为，禁止按评测文本、具体景点或测试名称添加生产特例。
- 凭据不进入 Git 或日志，完整用户行程及精确位置不写日志。
- 完成提交代码及测试记录，交由独立 merger 与阶段 review。
