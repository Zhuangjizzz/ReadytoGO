## What to build

真实千问理解中英行程，并依据候选资料分析设施、解释推荐。

## Acceptance criteria

- [x] 基础 openai SDK 接入既有千问；解析、匹配辅助和候选分析有结构化契约。
- [x] 限长、原文顺序、显式及否定需求、unsupportedNeeds、ID/字段校验正确。
- [x] 坐标路线取服务数据；设施推断不覆盖原始肯否定，排序由共用规则计算。
- [x] 有界超时、一次修复、批量说明/缓存和回退有效；多样真实输入验证，无特定样例代码或提示词。

## Execution constraints

- 使用独立工作树与分支，开始确认基于集成分支，完成前合入集成分支最新提交。
- 使用 tdd，在规格约定的公开 HTTP、正式导入及浏览器行为入口验证。用户授权直接执行，不重复询问。
- 实现通用输入行为，禁止按评测文本、具体景点或测试名称添加生产特例。
- 凭据不进入 Git 或日志，完整用户行程及精确位置不写日志。
- 完成提交代码及测试记录，交由独立 merger 与阶段 review。
