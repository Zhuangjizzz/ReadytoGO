# 04: 手动逐站规划与本机恢复

Status: ready-for-agent
Type: task
Stage: 3
Blocked by: 02, 03

Parent: [开发规格](../spec.md)

## What to build

规划 1–10 站，替换、跳过、重排，刷新继续使用。

## Acceptance criteria

- [ ] 增删换序、重复确认、稳定 stopId/revision；跳过保留景点。
- [ ] 逐站独立预览和重试，主推荐最多两个备选、完整列表保持规划语境。
- [ ] 重排接续在途结果且复用路线；位置与全局条件变化按规格重算。
- [ ] 保存一份行程，清除缓存，存储不可用和未知版本可继续。

## Execution constraints

- 使用独立工作树与分支，开始确认基于集成分支，完成前合入集成分支最新提交。
- 使用 tdd，在规格约定的公开 HTTP、正式导入及浏览器行为入口验证。用户授权直接执行，不重复询问。
- 实现通用输入行为，禁止按评测文本、具体景点或测试名称添加生产特例。
- 凭据不进入 Git 或日志，完整用户行程及精确位置不写日志。
- 完成提交代码及测试记录，交由独立 merger 与阶段 review。
