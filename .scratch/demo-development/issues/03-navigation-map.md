# 03: 详情、真实地图、导航与询问卡

Status: ready-for-agent
Type: task
Stage: 2
Blocked by: 01

Parent: [开发规格](../spec.md)

## What to build

从候选查看详情地图，选择导航起点，使用高德或双语询问卡。

## Acceptance criteria

- [ ] 地图按需加载、选点、卡片双向联动，失败保留列表。
- [ ] 详情来源可读，网页/App/复制入口可用，缺坐标不生成错误链接。
- [ ] 定位回退及一次转换正确；切导航起点重算，失败清空旧数字。
- [ ] 中英切换、五句询问卡、移动触控和横屏可用；地图配置如实记录。

## Execution constraints

- 使用独立工作树与分支，开始确认基于集成分支，完成前合入集成分支最新提交。
- 使用 tdd，在规格约定的公开 HTTP、正式导入及浏览器行为入口验证。用户授权直接执行，不重复询问。
- 实现通用输入行为，禁止按评测文本、具体景点或测试名称添加生产特例。
- 凭据不进入 Git 或日志，完整用户行程及精确位置不写日志。
- 完成提交代码及测试记录，交由独立 merger 与阶段 review。
