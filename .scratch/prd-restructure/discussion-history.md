Status: needs-info

## 目标

整合北京版与上海版原稿，形成可供实现与验收按需读取的 PRD，在 README 建立索引，并通过 grilling 讨论明确开发内容。

## 已确认的文档决定

- 使用 writing-for-agents：总入口提供读取条件，细则按任务拆分，同一规则只在一个权威位置定义。
- 删除当前 PRD 中的一天版、短期目标、按工期裁剪及阶段排期表述。
- 功能按是否纳入开发范围确认；PRD 只保留纳入的内容及其边界、规则和验收。
- 两份原稿保存在 [sources](sources/README.md)，用于追溯。
- 2026-10-09 已确认单起点急需任务、AI 工具检索与结构化输出、显式偏好政策和完整网页交付；具体匹配、推荐、交互与失败规则继续讨论。

## 文档事实

- 北京版明确替换上海版的城市、数据源和搜索半径：北京东城/西城、政府数据加高德、1 公里扩大至 2 公里。
- 北京版已描述一键急需、首次情况解析、结果页微调、个性化解释和英日韩界面。
- 景点厕所速查和用户自选 2–4 站规划是两个不同的用户任务。
- 当前任务范围根据第一轮回答确定为单起点急需查询；AI 职责已由用户扩展，旧稿仅解析/解释的分工被替换。
- 已核对两份原稿、现有 CSV 和存档接口摘要；外部服务本次未重测。事实由读取数据或来源验证，不要求用户猜答案。

## 本轮查明的事实

- [现有 CSV](../../data/BJ-ToiletInfo.csv) 为原始资料，未见已清洗 JSON、数据库文件、向量索引或匹配服务；东城/西城有 2,213 条记录，政府编号唯一。
- CSV 有名称、地址、区县、街道乡镇、编号和坐标，没有高德 POI ID 或标准楼层；未找到跨来源映射表。
- 坐标有十进制度、度分秒和经纬互换，空间匹配需要先清洗并核对坐标系。
- [高德存档摘要](../api-readiness/smoke/amap-capabilities-summary.json) 与[补充搜索记录](../api-readiness/smoke/amap-basic-search-check.json)表明基础搜索、步行耗时和固定坐标转换曾成功；楼层真实样例仍不足。
- [千问请求记录](../api-readiness/smoke/qianwen-request.json)只验证短 JSON 连通性，没有 tools/function calling 或多轮搜索；[摘要](../api-readiness/smoke/qianwen-summary.json)不能作为端到端工具流程通过的证据。
- 上述接口证据采集于 2026-10-08，本轮未重新请求外部服务。
