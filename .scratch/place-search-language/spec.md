## 诊断与验证

### 根因与官方接口

- 原 `/places/search` 忽略已解析的语言参数，并把 `nameEn` 固定置空；`PlacePicker` 和 AI 待确认地点列表固定读取 `nameZh`。
- 高德 POI 2.0 的文字搜索、周边搜索、ID 搜索均支持 `langCode=en`，默认中文 `zh`。官方注明 POI 多语言搜索为高级服务，需通过工单联系开通；v3 文档同样注明，并非切换到 v3 即免权限。
- 当前 Key 的真实测试：普通中文搜索成功；显式 `langCode=zh` 和 `langCode=en` 均返回 `status=0 / infocode=10012 / INSUFFICIENT_PRIVILEGES`，见 [上游原始错误摘要](upstream-language.json)。未尝试其他 Key、账号或非官方入口。
- 官方来源（2026-10-09 核对）：[POI 2.0](https://lbs.amap.com/api/webservice/guide/api-advanced/newpoisearch)、[POI v3](https://lbs.amap.com/api/webservice/guide/api-advanced/search)、[错误码](https://lbs.amap.com/api/webservice/guide/tools/info)。
